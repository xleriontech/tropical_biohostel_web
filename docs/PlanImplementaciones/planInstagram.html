02 · Los 6 pilares

Estrategia integral

Cada pilar aborda una dimensión crítica. Juntos forman un sistema que convierte seguidores en huéspedes.

🎨
Crítico

Identidad Visual

Alinear toda la comunicación con el nuevo manual de marca: colores, tipografías, tono.

→ Paleta: Bosque, Sol, Hoja, Crema
→ Tipografías: Fraunces + Inter
→ Fotografía: luz natural, cálida
📸
Crítico

Contenido Estratégico

5 pilares de contenido: Experiencia, Utilidad, UGC, Contexto local, Behind the scenes.

→ 35% Experiencia vivida
→ 20% Utilidad práctica
→ 15% UGC · 15% Local · 15% BTS
💬
Alto

Narrativa Emocional

Activar 4 disparadores: pertenencia, calma, curiosidad y aspiración sensorial.

→ Tono: cálido, poético, sensorial
→ Copy: gancho + cuerpo + CTA suave
→ Emojis: máximo 2 por post
🤖
Alto

Automatización IA

WhatsApp Business API + ManyChat para respuestas 24/7 y cierre de ventas automático.

→ Respuestas a keywords (PRECIO, FECHAS)
→ Secuencias de follow-up 7 días
→ Conserje digital RAG
👥
Medio

UGC y Comunidad

Sistema proactivo para capturar y reutilizar contenido de huéspedes reales.

→ Solicitud en check-in
→ Hashtag: #TropicalBiohostel
→ Historias destacadas por categoría
💰
Crítico

Conversión Directa

Eliminar OTAs con beneficios exclusivos para reservas directas por WhatsApp.

→ Mejor tarifa garantizada
→ Beneficios exclusivos (upgrade, desayuno)
→ Recuperación de carritos abandonados
